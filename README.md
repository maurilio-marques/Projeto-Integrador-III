# Análise de Custos em Operadora de Saúde

## 📌 Visão Geral do Projeto
Este projeto foi desenvolvido para analisar os custos de internações e consultas na operadora de saúde BANESTES, com o objetivo de identificar oportunidades de otimização de recursos e redução de gastos. Utilizando dados reais e anonimizados, a equipe explorou padrões de custos, frequência de procedimentos e características demográficas dos beneficiários, com foco nos diferentes planos oferecidos: Titular, Familiar e Funcionários.

Os resultados foram consolidados em dashboards interativos no Power BI, permitindo uma visualização clara e estratégica dos dados para auxiliar na tomada de decisões.

## 🎯 Objetivos
- ✔ Analisar custos de internações e consultas para identificar gastos excessivos.
- ✔ Comparar os planos (Titular, Familiar e Funcionários) em termos de custos e cobertura.
- ✔ Mapear a distribuição geográfica dos beneficiários para entender a demanda por região.
- ✔ Identificar procedimentos mais frequentes e seus impactos financeiros.
- ✔ Desenvolver dashboards interativos para facilitar a visualização e análise dos dados.
